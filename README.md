🚀 Network Architecture to Expand

A scalable SME network designed to handle growth, failures, and real-world traffic like a pro.

📌 Overview

This project is a full-scale SME network design built using Cisco Packet Tracer.

Instead of a basic setup, this network is designed to:

  Handle high traffic loads (20K users/hour)
  Support future expansion & acquisitions
  Maintain high availability and monitoring

👉 Think of it as building a mini ISP-level architecture for a company.

🏗️ Architecture
🔷 Hierarchical Design (Core–Distribution–Access)

Core Layer → Fast backbone routing
Distribution Layer → Policies, routing, segmentation
Access Layer → End-user devices

✔ Scalable
✔ Fault-tolerant
✔ Easy to manage

🧩 Network Segmentation

🔹 Engineering
  260+ Staff PCs
  40 Production Servers (SPU Model)
🔹 Sales
  Back-office systems
  Customer support
  Remote desktops
  VPN infrastructure
🔹 Management
  Executive systems
🔹 Shared Resources
  Printers
  File servers

👉 Each sub-division runs on its own subnet for security + efficiency

⚙️ Key Features
🔁 Service Production Unit (SPU)

Load-balanced server groups
Active + hot-standby architecture
High availability design
🌍 VPN Connectivity

Secure remote access for global sales team
  Remote desktop support
  ~10 Mbps/user traffic handling
📊 Traffic-Aware Design
  High-load services (A & B → 10K users/hour each)
  Future scaling → 20K users/hour
  Load distribution across production servers
